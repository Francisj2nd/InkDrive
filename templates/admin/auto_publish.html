How It Works
1. Trend Discovery
Gemini searches the web for the top trending topic in each selected category.
2. Research
Gemini gathers facts, stats, and expert perspectives using live Google Search.
3. Article Generation
A full SEO-optimised article with images is written using the InkDrive pipeline.
4. Auto-Publish
The article is saved and immediately published to the public feed — no human needed.
Deployment tip: Set the environment variable ENABLE_SCHEDULER=true on exactly one server worker so the background scheduler runs without duplication. Alternatively, run python auto_publisher.py via a system cron job or Render Cron Service.
